# Folio — Portfolio Tracker

Personal investment portfolio tracker. Built as a PWA.

## Deploy to GitHub Pages

1. Create a new repository named `folio` on GitHub
2. Upload all files in this folder to the repo
3. Go to **Settings → Pages → Source → Deploy from branch → main → / (root)**
4. Your app will be live at: `https://northpassornsiri.github.io/folio`

## Add to Home Screen (iOS)
1. Open `https://northpassornsiri.github.io/folio` in Safari
2. Tap Share button → **Add to Home Screen**
3. Done — Folio icon appears on your home screen

## Files
- `index.html` — Main app
- `manifest.json` — PWA config
- `sw.js` — Service worker (offline support)
- `icon-192.svg` — App icon
